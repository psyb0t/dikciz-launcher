# Recipes

These are the same focused procedures packaged as MCP resources in the APK. Each recipe links to the relevant full guide and states how to verify its outcome. Discover the installed build's tool schemas before calling a command. Replace example IDs, widget addresses and paths with the intended phone objects.

For a complete illustrated project, follow the [Travel todo tutorial](todo-app-tutorial.md). For connected Lua and HTML code, start with the [two-input event pipeline](recipe-event-setup.md), then read its [Lua receiver](recipe-event-lua.md) and [HTML receiver](recipe-event-widget.md).

The navigation below lists every packaged recipe. The [MCP resource guide](mcp-resources.md) explains how an agent reads them on the phone without downloading this website.
